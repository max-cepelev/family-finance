# Семейный бюджет (Android + веб-доступ)

Учёт личных финансов для двоих с синхронизацией через Syncthing. Контекст и план — в [docs/HANDOFF.md](docs/HANDOFF.md), примеры уведомлений банков — в [docs/bank-formats.md](docs/bank-formats.md).

## Модули

| Модуль | Что внутри | Зависит от Android |
|---|---|---|
| `core/domain` | модель (Account, Category, Transaction…, деньги в копейках `Long`), last-writer-wins, импорт `.mmbak` (`MmbakReader`), CSV | нет |
| `core/data` | Room (таблицы с полями синхронизации `uid/updatedAt/deleted/deviceId`), репозитории, Hilt-модули, чтение `.mmbak` через `android.database.sqlite` | да |
| `app` | Compose + Material 3, веб-сервер Ktor с HTML/htmx в `web/`, встроенные CSS/JS | да |

## Сборка

Нужны JDK 21, Android SDK Platform 36 и Build Tools 36.0.0. Kotlin и Gradle скачиваются
через Gradle Wrapper: отдельные `kotlinc`, системный Gradle, Node.js и npm для веб-доступа не нужны.

На Linux SDK может находиться в `$HOME/Android/Sdk`. Создайте `local.properties` (не попадает в git)
со строкой `sdk.dir=/полный/путь/к/Android/Sdk` или задайте `ANDROID_HOME`.
Если компоненты SDK ещё не установлены, команда из `cmdline-tools/latest/bin`:

```bash
sdkmanager 'platforms;android-36' 'build-tools;36.0.0' 'platform-tools'
```

Обычная сборка:

```bash
./gradlew :app:assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`. Debug-приложение имеет отдельный идентификатор
`com.familyfinance.debug` и не заменяет основное приложение с данными.

Старый macOS-путь `../.tools/jdk/Contents/Home` не нужен. Подпись release настраивается отдельно
через локальный `keystore.properties`; debug-сборка не требует release-ключа.

## Тесты

```bash
./gradlew :core:domain:test :core:data:testDebugUnitTest :app:testDebugUnitTest
```

Для проверки реального бэкапа добавьте `-Pmmbak.path=/полный/путь/к/backup.mmbak`.
Без него тесты на реальном бэкапе пропускаются. С ним проверяется, что остаток каждого счёта
после импорта совпадает с суммой строк Money Manager, а повторный импорт ничего не меняет.

`AppSmokeTest` (Robolectric) запускает настоящее приложение на импортированных данных, проходит
по экранам (февраль 2021: список, правка, новая операция с «Сохранить и ещё», календарь, статистика,
счета) и кладёт скриншоты в `app/build/screenshots/`. Часовой пояс теста — UTC+5: Money Manager хранил даты
как полночь по местному времени, где делался бэкап.

## Веб-доступ с компьютера

Это не отдельное облачное приложение: Ktor работает внутри Android-приложения и использует те же
репозитории и базу. На телефоне откройте «Ещё» → «Доступ с компьютера», включите доступ и введите
в браузере показанный адрес и код. Компьютер и телефон должны быть в одной локальной сети.
Доступ работает по HTTP внутри доверенной домашней сети; не публикуйте порт в интернете.

Реализовано:

- Операции по дням, поиск, создание, редактирование, разделение по категориям и удаление.
- Месячная статистика доходов/расходов, доли категорий, раскрытие подкатегорий и переход к операциям.
- Счета с остатками за всё время, итогами по группам и переходом к операциям счёта.
  Скрытые счета доступны для истории, но исключены из итогов.
- Каталог доходных/расходных категорий с подкатегориями, архивом и количеством операций.
- CSV-выгрузка за месяц, год или всё время, по всем счетам или одному; учитываются обе стороны переводов.
- Отрицательные операции (скидки/возвраты) сохраняют знак. Для них CSV использует явные типы
  «возврат расхода», «возврат дохода», «обратный перевод», чтобы отличать их от старых таблиц,
  где минус перед обычным «расходом» обозначал списание. Для их импорта нужна версия с поддержкой этих типов.
- Точные фильтры счёта/категории сохраняются при поиске, смене месяца и обновлении списка после правки.

Пока только на телефоне: настройка счетов/кредитных карт, редактирование и объединение категорий,
импорт CSV/выписок/`.mmbak`, бюджеты и остальные Android-настройки. В веб-статистике пока только месяцы.
CSV — табличная выгрузка, а не полный бэкап: она не хранит все служебные поля, структуру разделённых
операций, чеки и отдельную сумму зачисления межвалютного перевода.

Веб-тесты без телефона:

```bash
./gradlew :app:testDebugUnitTest --tests 'com.familyfinance.web.*'
```

Для ручной проверки в браузере есть опциональный сервер с **синтетическими данными**, без авторизации
и без доступа к телефону/настоящей базе. Он слушает только `127.0.0.1:18080` и выключается через 10 минут:

```bash
./gradlew :app:testDebugUnitTest --tests 'com.familyfinance.web.WebPreviewTest' -Pweb.preview=true
```

Откройте `http://127.0.0.1:18080/ops?month=2026-10`. Изменения в таком режиме живут только в памяти.
Сервер можно завершить раньше запросом `POST /__preview/stop`.

## Импорт `.mmbak`

- uid записей — UUID, детерминированно выведенные из uid Money Manager: повторный импорт (или импорт на втором телефоне) не создаёт дублей.
- `updatedAt` берётся из времени изменения в бэкапе, запись идёт по last-writer-wins — правки, сделанные после импорта, не затираются.
- Перевод (две строки `INOUTCOME` с общим `txUidTrans`) становится одной операцией типа `TRANSFER`.
- Удалённые в Money Manager категории и группы переносятся как архивные: на них ссылаются старые операции.
- Операции с псевдокатегориями `-3/-4` («изменение баланса») импортируются без категории.

## Синхронизация через общую папку

- Каждый телефон пишет свои изменения в свой файл `familyfinance-<deviceId>.jsonl` в выбранной папке
  (одна JSON-строка на запись, первая строка — имя устройства). Чужие файлы только читаются, поэтому
  у Syncthing не бывает конфликтов; его копии `*.sync-conflict-*` игнорируются.
- Локальные правки попадают в очередь `pending_changes` в той же транзакции, что и сама правка;
  изменения, полученные с другого телефона, в очередь не попадают и обратно не отправляются.
- Конфликты: побеждает больший `updatedAt`, при равенстве — больший `deviceId`, так что оба телефона
  выбирают одну и ту же версию.
- Позиция чтения каждого чужого файла хранится в `sync_offsets`; недописанная последняя строка ждёт
  следующего раза, запись неизвестного типа (от более новой версии приложения) останавливает чтение
  этого файла, ничего не пропуская.
- При первом подключении папки выгружается всё локальное состояние: полный бэкап — около 3,9 МБ.
- Движок (`core/domain/.../sync`) не зависит от Android: папка — интерфейс `SyncFolder`
  (SAF на телефоне, обычный каталог в тестах), так что WebDAV или облако подключаются как ещё одна реализация.
- Синхронизация идёт, пока приложение на экране: при открытии, через 2 с после правки и раз в минуту.
