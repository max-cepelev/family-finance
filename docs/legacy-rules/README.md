# Правила разбора уведомлений (исходник)

`RuBankRules.java` и его тест — правила разбора пушей Сбера, Т-Банка и Райффайзена, написанные
для прежнего патча Money Manager. Это наш собственный код, без зависимостей от Money Manager.

Здесь он лежит как образец для переноса на Kotlin в приложение. После переноса папку можно удалить.
